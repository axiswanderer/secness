Build a SaaS todo app with teams and admin roles.

- Node.js + Express + TypeScript API, PostgreSQL database, simple web frontend.
- Users register and log in (JWT auth). Each user belongs to one team.
- Team members can create, view, update and delete their team's todos, comment on
  todos, attach files, and add a link to a todo that shows a preview (page title).
- Users can search their todos and update their own profile and settings.
- Admins can list and delete users.
- Ship a Dockerfile and docker-compose.yml so it runs with `docker compose up`.
